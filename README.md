# CineMatch 🎬

Projeto de portfólio desenvolvido com React, Vite e Tailwind CSS.

O objetivo é criar uma interface para descobrir filmes e organizar
uma lista pessoal do que assistir.

## Etapa atual

Etapa 1 — estrutura inicial e landing page responsiva.

### Implementado

- Cabeçalho com navegação.
- Apresentação principal.
- Seção de funcionalidades.
- Espaço reservado para o catálogo.
- Rodapé.
- Layout responsivo.

### Próximas etapas

- Catálogo JSON carregado com Fetch.
- Busca por título e filtro por gênero.
- Modal com informações dos filmes.
- Lista pessoal com localStorage.
- Integração com uma API de filmes.

## Tecnologias

- React
- JavaScript
- Vite
- Tailwind CSS
- Git e GitHub

## Executar localmente

Requisito: Node.js 22.12+ e npm.

```bash
npm install
npm run dev
```

Abra o endereço exibido pelo Vite no terminal.

## Gerar o build

```bash
npm run build
```

## Observação

Esta primeira etapa apresenta a interface inicial.
O catálogo e as demais interações serão desenvolvidos nas próximas etapas.
